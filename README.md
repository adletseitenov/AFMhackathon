# КӨЗ (KÓZ) · AI Media Watch

ИИ-консоль аналитика **АФМ** для выявления признаков **незаконного игорного бизнеса и финансовых пирамид** в соцсетях.
Проект трека **«AI Media Watch»** хакатона **АФМ AI Hackathon 2026**.

> «КӨЗ» (каз. *глаз*) — непрерывно собирает посты соцсетей, оценивает риск **собственной обученной моделью**, объясняет признаки нарушения на русском и выстраивает **приоритетную очередь** «что проверять первым».

## Что внутри (по критериям оценки)

1. **Актуальность + обоснование AI** — мониторинг соцсетей вручную невозможен по объёму; AI обязателен.
2. **Своя модель, независимая от сервисов** — риск-классификатор `TF-IDF (word + char_wb) + ручные сигналы → LogisticRegression` (только scikit-learn, **без torch и без внешних API**). Обучается локально за секунды. Метрики: **macro-F1 ≈ 0.94** (реалистичная confusion matrix), экран `/api/metrics`.
3. **ИБ + этика** — только публичные данные; **human-in-the-loop** (система *приоритизирует для проверки*, не блокирует автоматически); объяснимость каждого флага; SSRF-защита в live-проверке.
4. **Реализуемость + масштаб** — модульный пайплайн, авто-роутеры, путь MVP (SQLite) → прод (Postgres + очередь).
5. **Презентация + тех-защита** — светлая аналитическая консоль: лента/очередь, drill-down с доказательствами по модальностям, граф связей, тренды, PDF-досье, живая проверка.

## Запуск (Windows, одна команда)

```bat
setup.bat   :: создаёт .venv и ставит зависимости (один раз)
run.bat     :: поднимает сервер на http://127.0.0.1:8000
```

Вручную (любая ОС, Python 3.11+):

```bash
python -m pip install -r requirements.txt
python -m scripts.gen_dataset      # сгенерировать датасет RU+KZ (опц. — уже в репо)
python -m app.model.train          # обучить модель -> app/model/artifacts/ (опц. — уже в репо)
python -m scripts.build_demo       # собрать демо-ленту (опц. — уже в репо)
python -m uvicorn app.main:app --port 8000
```

Открыть **http://127.0.0.1:8000** — лента наполняется автоматически (фоновый «дрип» seed-постов).

## Проверка перед защитой

```bash
python -m pytest tests -q     # 150 тестов
python -m scripts.dry_run     # smoke-тест всех 9 роутов -> 200
```

Фронтенд-библиотеки (Tailwind/Alpine/Chart.js/vis-network) **завендорены в `web/vendor/`** — консоль работает **офлайн** (не зависит от Wi-Fi на площадке).

## Архитектура

```
ingestion (seed-дрип + live yt-dlp/upload)
  → extractors (текст/сущности; ленивые Whisper/OCR/CLIP с кэшем)
  → СВОЯ МОДЕЛЬ (риск 0–100 + категория + объяснение)
  → decision (скоринг/рекомендация/аудит)
  → консоль (лента · граф · тренды · PDF · живая проверка)
```

- Бэкенд: **FastAPI + SQLite**. Своя модель: **scikit-learn**. PDF: **reportlab**.
- Роуты подключаются авто-роутером из `app/**/routes.py` (фичи не правят `main.py`).
- Документы защиты: `docs/pitch/` — питч, демо-скрипт, Q&A и **слайд-дек `docs/pitch/deck.html`** (открыть в браузере, листать стрелками; самодостаточный, офлайн). Дизайн/план: `docs/superpowers/`.

## Этика и ограничения

Система выдаёт **риск-сигнал для аналитика**, а не приговор. Все флаги объяснимы. Используются только публичные данные; персональные данные не профилируются. Окончательное решение — за человеком.
