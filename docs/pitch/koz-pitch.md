# Питч «КӨЗ» (KÓZ) — AI Media Watch · 3 минуты

> Хронометраж жёсткий: 5 блоков, ~3:00. Один спикер. Слайды переключаются по таймкодам.
> Язык защиты — русский. Все экраны консоли — на русском.

## Тайминг и привязка к критериям (каждый критерий = 20 баллов)

### 0:00–0:30 — Проблема + актуальность (Критерий №1: актуальность + обоснование AI)
«В соцсетях Казахстана ежедневно публикуются тысячи роликов с рекламой нелицензированных
онлайн-казино, финансовых пирамид и реферальных схем. Вручную мониторить TikTok, Instagram,
YouTube и Telegram физически невозможно — поток круглосуточный, контент мультимодальный
(видео + речь + текст на экране), да ещё на смеси русского и казахского. Это и есть
обоснование AI: масштаб и мультимодальность не разбираются руками. Мы сделали "КӨЗ" —
с казахского "глаз" — ИИ-глаз АФМ над соцсетями.»

### 0:30–1:15 — Решение + лента (Критерий №5: качество презентации; задел под №1)
«Вот аналитическая консоль. Посты "капают" в ленту в реальном времени — это симуляция
непрерывного потока мониторинга. Каждый пост автоматически оценивается нашей моделью и
встаёт в приоритетную очередь по риску: красный (эскалация ≥70) → жёлтый (проверка 40–69) →
зелёный (чисто <40). Аналитик сразу видит, что проверять первым, и не тонет в потоке.»
(Показать сортировку по риску, цветовые бейджи риска, бейджи категории и платформы.)

### 1:15–2:00 — Своя модель + метрики + мультимодал + drill-down (Критерий №2: собственная AI-модель, независимая от внешних сервисов)
«Кликаем по посту с верхним риском. Скоринг даёт НАША обученная модель. Под капотом —
TF-IDF по словам и по символам (char n-grams ловят искажённые "kаzино", "1xб3т") плюс наши
инженерные сигналы (обещание дохода, бренды казино/букмекеров, призыв в личку, реф-схема,
промокод, крипто-реквизиты, срочность) — всё это сливается и подаётся в обученную нами
голову-классификатор (LogisticRegression, scikit-learn). Никаких внешних платных API в
скоринге — модель тренируется локально за секунды и работает офлайн. Вот метрики: macro-F1,
F1 по классам и confusion matrix (экран /api/metrics). Честно: на нашем курируемом датасете
RU+KZ метрики сильные; для боевого развёртывания нужен больший размеченный корпус — это
вопрос данных, не архитектуры. В drill-down — доказательства по всем модальностям:
транскрипт речи (Whisper), текст с экрана (OCR/EasyOCR), визуальные концепты (CLIP),
сработавшие паттерны и объяснение "почему опасно" на русском. Жмём "Экспорт дела" —
готовое PDF-досье для передачи.»

### 2:00–2:30 — Граф связей + live (Критерий №2 продолжение + №1: скрытые взаимосвязи)
«Граф связей: эти аккаунты пушат один и тот же бренд казино через один Telegram-канал и
один промокод — координированная сеть, видно сразу, руками такое не вылавливается. И живой
путь: вставляем ссылку или грузим видео — реальный мультимодальный разбор прямо на сцене →
вердикт за секунды.»

### 2:30–3:00 — Этика, масштаб, призыв (Критерий №3: ИБ+этика; Критерий №4: реализуемость+масштаб)
«Этика встроена в архитектуру: только публичные данные, минимизация PII, human-in-the-loop —
система приоритизирует материал для проверки, а НЕ блокирует и НЕ обвиняет автоматически;
финальное решение за аналитиком. Каждый флаг объясним, все действия пишутся в аудит-лог,
порог калибруется в пользу precision (меньше ложных обвинений). Масштаб: модульные
stateless-экстракторы, путь MVP на SQLite → прод на Postgres + очередь задач + объектное
хранилище медиа. КӨЗ закрывает формулировку трека один-в-один: собрать → разобрать →
оценить риск собственной моделью → объяснить → приоритизировать для проверки.»

## План слайдов (5 слайдов + титул)
0. **Титул** — «КӨЗ (KÓZ) · AI Media Watch · АФМ AI Hackathon 2026».
1. **Проблема** — масштаб мошеннической рекламы в соцсетях РК (казино/пирамиды/реф-схемы),
   мультимодальность и двуязычие RU+KZ; почему руками нельзя → AI обоснован.
2. **Решение** — скриншот консоли: лента + приоритетная очередь по риску (красный/жёлтый/зелёный).
3. **Своя модель + метрики** — схема (TF-IDF слова + char n-grams + наши инженерные сигналы →
   наша голова LogisticRegression), macro-F1 и F1 по классам, confusion matrix; явно:
   «обучена нами, локально, без внешних API в скоринге».
4. **Мультимодал + граф** — drill-down с доказательствами по модальностям (транскрипт/OCR/CLIP/
   паттерны/объяснение) + граф координированной сети.
5. **Этика + масштаб** — публичные данные, human-in-the-loop, объяснимость, аудит-лог; путь MVP→прод.
