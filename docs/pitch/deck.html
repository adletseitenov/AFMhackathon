КӨЗ

ИИ-консоль аналитика АФМ для выявления незаконного игорного бизнеса и финансовых пирамид в соцсетях.

«КӨЗ» (каз. глаз) — собирает посты, оценивает риск своей обученной моделью, объясняет признаки и приоритизирует материалы для проверки.

Проблема

Соцсети — главный канал вовлечения в нелегальный гемблинг и пирамиды

  • Тысячи постов в день: реклама нелицензированных казино (1xBet, Mostbet, Vavada), «доход 30% в месяц», реф-схемы, призывы в Telegram.
  • Вручную это невозможно отсмотреть и приоритизировать — нужен ИИ.
  • Контент мультимодальный: видео, аудио, субтитры, текст с экрана, визуальные маркеры.
Решение

Аналитическая консоль: собрать → оценить → объяснить → приоритизировать

Лента / очередь

Приоритет по риску

Поток постов авто-скорится и сортируется: эскалация ≥70на проверку 40–69чисто <40

Drill-down

Доказательства + объяснение

Транскрипт, OCR, визуал-концепты, сработавшие паттерны, «почему опасно», PDF-досье.

Граф связей

Скрытые сети

Один бренд / Telegram / промокод / кошелёк связывает аккаунты в координированные кластеры.

Тренды · Живая проверка

Масштаб + ad-hoc

Сводка по категориям/платформам и проверка любого поста по ссылке/файлу.

Критерий №2 — своя модель, независимая от сервисов

Это не обёртка над ChatGPT — это наша обученная модель

TF-IDF (word + char_wb, RU+KZ) + инженерные сигналы → LogisticRegression

  • Только scikit-learn. Без torch, без внешних API в инференсе. Обучается локально за секунды.
  • Объяснимость «из коробки»: риск-вклад каждого сигнала → причины на русском.
  • 0.94 macro-F1 на отложенной выборке (реалистичная confusion matrix, не идеальная) — экран /api/metrics.
Этика и ИБ (критерий №3) · Масштаб (критерий №4)

Сигнал для аналитика, а не приговор

Этика / ИБ

Human-in-the-loop

Система приоритизирует, не блокирует и не обвиняет автоматически. Только публичные данные, минимизация PII, объяснимость, контроль ложных срабатываний, SSRF-защита live-проверки.

Масштаб

MVP → прод

Stateless-воркеры экстракторов + очередь, батчинг; путь SQLite → Postgres + объектное хранилище. Авто-роутеры: фичи подключаются без правок ядра.

Демо за 3 минуты (критерий №5)

Что показываем вживую

  • 1. Лента: посты капают, авто-скор, очередь сортируется по риску.
  • 2. Клик по топ-риску → доказательства по модальностям + объяснение → «Экспорт дела (PDF)».
  • 3. Граф: 6 аккаунтов пушат один бренд через один Telegram — координированная сеть.
  • 4. Живая проверка ссылки → вердикт. Затем метрики модели.

Консоль работает офлайн (библиотеки завендорены) — не зависит от Wi-Fi на площадке.
